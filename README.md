# CaseFlow OS 案件協同管理系統

> 🌟 **讓團隊協作告別雜亂的 LINE 群組與流水帳，打造「不漏球、責任明確、視圖自由」的案件管理新體驗。**

CaseFlow OS 是一套專為旅遊業（如：馬航怡保團）、活動籌辦（如：公司年度春酒）等複雜多工專案設計的案件協同管理系統。透過結構化的三層式案件管理與靈活的檢視模式，讓主管、專案負責人、以及合作夥伴/工讀生都能專注於自身任務，不漏掉任何關鍵死線。

---

## 🚀 系統核心鐵律
1. **不漏球 (Zero-Miss)**：所有待辦細項均有到期日與自動提醒。
2. **責任明確 (Clarity)**：誰負責、誰可以看、誰在等待，一目了然，杜絕推諉。
3. **視圖自由 (Flexibility)**：日曆看今日重點、清單看專案細節、甘特圖掌握全局時程。

---

## 🧱 核心三層結構
* **Level 1: Case (案件/專案)**：獨立的專案大項（例如：`2026/09/15 馬航怡保團`）。
* **Level 2: Task Group (任務分組)**：案件底下的功能分組（例如：`票務組`、`飯店與 Local 組`、`證件名單組`）。
* **Level 3: Task Item (待辦細項)**：真正執行的具體動作（包含到期日、獨立備註、提醒、指派可見人員與留言討論）。

## 📖 快速上手指南
請參考詳細的 [員工操作手冊 (HANDBOOK.md)](file:///d:/Projects/CaseFlow_OS/HANDBOOK.md) 來快速了解以下操作：
- **📅 日曆模式**：每日早上看紅黃綠燈（🔴 已過期 / 🟡 今日必做 / 🟢 已完成）。
- **📋 案件模式**：如何新增事項、查看備註、進行項目級留言（`@對象`）溝通。
- **📊 甘特圖模式**：一眼看清時間跨度與專案進度百分比。
- **🔒 權限與可見度**：了解如何管理特定任務的可見度，確保資訊不洩漏、不超載。

## 🛠️ 開發與快速啟動 (Quickstart)

### 1. 複製專案
```bash
git clone https://github.com/voyagermartin/CaseFlow_OS.git
cd CaseFlow_OS
```

### 2. 建立虛擬環境並安裝依賴
```bash
# 建立虛擬環境
python -m venv .venv

# 啟用虛擬環境 (Windows)
.venv\Scripts\activate

# 啟用虛擬環境 (macOS/Linux)
source .venv/bin/activate

# 安裝依賴 (後續開發請在此處安裝)
# pip install -r requirements.txt
```

### 3. 資料庫配置
本專案預設使用輕量且無需安裝的 SQLite 資料庫（`*.db`），檔案將會自動排除在 Git 版本控制之外，確保本地端開發測試資料不污染正式環境。
